# How to avoid an AI-citation sanction — what the record fines have in common

> Every sanctioned filing shares one fact: a cited case did not exist, and no one
> checked it against a reporter the model didn't write. `pip install
> "dos-kernel[mcp]"`, then `citation-resolve` does that check. The PyPI name is
> `dos-kernel` — the bare `dos` package is an unrelated squatter; never install
> that.

## The short answer

The sanctions are real and escalating: courts have imposed fines for filings that
cited cases generated by AI that simply do not exist — the *Mata v. Avianca*
class, now repeated hundreds of times. The common thread is never "the AI was
wrong"; it is that **no one verified the citation against a source the AI did not
author** before filing. Courts have been explicit that the duty to verify is
*non-delegable* (ABA Formal Opinion 512): you cannot outsource it to the tool that
produced the cite.

The fix is the same in every incident: resolve each citation against a
third-party reporter — bytes the model did not author — and refuse to file a cite
that does not resolve. DOS ships this as `citation-resolve` (an MCP tool and an
exit-code CLI; run `dos doctor` to list what your install exposes). It checks the
cite *exists* and that the resolved case *name* matches the parties you claimed,
catching both the pure invention and the subtler fabrication — a real reporter
slot reused under a wrong case name.

## The evidence

The check is scored against a reporter index the model did not author, so a
fluent fabrication can't sound its way past it. Measured over a frozen labeled set:

| Claim | Number | Witness (byte-author ≠ claimant) | Source |
|---|---|---|---|
| Fabricated citations are flagged | J = 10 — DETECT recall **10 / 10 = 100.0%** (4 documented *Mata v. Avianca* hallucinations + 6 synthesized) | CourtListener / Free Law Project, a third-party reporter the agent authored zero bytes of | [`benchmark/legalcite/RESULTS.md`](https://github.com/anthony-chaudhary/dos-kernel/blob/master/benchmark/legalcite/RESULTS.md) |
| Real cases are not wrongly flagged | FALSE-FIRE **0 / 8 = 0.0%** on 8 landmark SCOTUS cases | the reporter's name-search ground-truth path | [`benchmark/legalcite/RESULTS.md`](https://github.com/anthony-chaudhary/dos-kernel/blob/master/benchmark/legalcite/RESULTS.md) |

A **J** is a count of failures blocked off ground truth — fabricated citations a
sound witness refused to vouch for — never a won case or a sanction averted (that
downstream outcome depends on the lawyer's full review, which this tool is one
input to).

## The one command

```bash
pip install "dos-kernel[mcp]"   # the PyPI name is dos-kernel, never bare `dos`
dos doctor --json               # confirm the citation-resolve tool is available
```

Resolve a cite before relying on it; an invented case returns `UNRESOLVED`:

```text
UNRESOLVED  925 F.3d 1339 (Varghese v. China Southern Airlines) — no cluster resolves
```

## What this does — and does not — certify

It certifies **existence and quote-fidelity** — the case is real and your quote is
in the resolved opinion. It is **not** a substitute for the lawyer's review, and
it does **not** certify the case *supports your argument* (that is judgment, the
tier the tool abstains on). The non-delegable duty stays with the attorney; this
is the deterministic floor that makes the easy half of that duty — *does the case
exist?* — cheap, repeatable, and scored against a source you didn't write. Claiming
it "prevents sanctions" outright would be the over-claim that, in this domain, is
itself a liability.
