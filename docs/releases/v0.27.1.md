**TL;DR** — The same release as v0.27.0, re-cut so it can actually ship. The
v0.27.0 tag landed on a commit whose CI was red (a concurrent loop's two
in-flight breakages — a Go-hook parity drift and a lint error — neither part of
the release work), so the publish pipeline's ci-green gate refused the upload and
PyPI never received 0.27.0. This patch fixes both breakages forward, lands on a
green trunk, and is the version that publishes. Pin `dos-kernel==0.27.1`.

## What ships (carried from v0.27.0)

- **`arbiter` — subagents stop false-denying their own in-lane edits (#188).** A
  subagent editing inside its ancestor's active lease is admitted, not
  hard-DENIED; the pretool gate resolves the lineage chain first
  (`src/dos/pretool_sensor.py`, `src/dos/run_id.py`, Go fast-path mirrored).
- **`decisions` — children report refusals up the lineage chain (#189).** A
  child's structural refusal propagates to the root run and folds into
  `dos status --children` (`src/dos/child_refusals.py`, `src/dos/lane_journal.py`).
- **`cli` — `dos top` surfaces the kernel's own background activity.** A
  BACKGROUND ACTIVITY panel folds the out-of-band actions (HALT / SCAVENGE /
  RECONCILE / ENFORCE) that were journaled but invisible (`src/dos/dispatch_top.py`).
- **`drivers` — `dos accounts` + the `provider_ledger` THIRD_PARTY witness.** The
  seat-pool seam and a new external-effect witness band (docs/261).
- **`arbiter` — tree-disjointness soundness (#144).** `norm_tree_prefix` truncates
  a glob at `?` and `[` as well as `*`, closing a false-disjoint (Py + Go parity).
- **`decisions` — RESUME_PROPOSED runs surface in the operator queue (#19).**

## New in this patch

- **`config` — the loop-economics floors as `dos.toml` data (#37).** Each of
  `efficiency` / `improve` / `productivity` / `efficiency_trend` grows a
  `policy_from_table` + `load_from_toml` pair (mirroring `dos.cooldown`);
  `load_workspace_config` folds the four tables, and `dos doctor --json` reports
  the armed floors under an `economics` section. A declared `[efficiency] floor`
  flips `dos efficiency` to COSTLY with no `--floor` flag — the dead-by-default
  floor, armed as data.
- **`ci` — two fix-forwards that turned the trunk green.**
  - The Go parity harness (`go/internal/hook/parity_test.go`) now reads the
    corpus's `operator_session` field and injects it as `in.OperatorSession`, so
    the native decider emits the same softened SELF_MODIFY WARN as Python (docs/355)
    instead of the old hard-deny — a false byte-drift, now closed.
  - Two ruff lints cleared: a missing `PulseDigest` type-only import in
    `src/dos/notify.py` and two unused imports in `src/dos/pulse.py`.
